# Changelog

All notable changes will be documented here.

## [2.0.0] - 2026-09-02

### Added

- Rich cross-platform terminal interface and interactive offline HTML dashboard.
- `.repocure.toml`, glob exclusions, rule suppressions, and resource limits.
- Quality and CI analyzers plus an expanded stable rule catalog.
- Scan timing, file counts, severity counts, and category counts.
- Reusable GitHub Action and native SARIF Code Scanning workflow.
- Branded SVG identity and a redesigned project homepage.

### Security

- Symlink avoidance, bounded file reads, bounded file counts, HTTPS-only remote sources, and non-interactive shallow clones.

## [1.1.0] - 2026-09-02

### Added

- Direct scanning of public HTTPS GitHub repository URLs.
- Secure shallow cloning into automatically cleaned temporary directories.
- Source information in all report formats.

## [1.0.0] - 2026-09-02

### Added

- Initial CLI and project health scoring.
- Security, performance, dependency, Git, Docker, documentation, and test analyzers.
- Text, JSON, and Markdown reports.
