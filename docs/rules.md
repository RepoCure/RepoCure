# Rule catalog

Rules have stable IDs grouped by analyzer:

- `SEC`: security
- `QLT`: code quality
- `PRF`: performance
- `DEP`: dependencies
- `DCK`: Docker
- `GIT`: repository hygiene
- `DOC`: documentation
- `TST`: tests
- `CIC`: CI/CD

Use `repocure rules` for the catalog shipped with your installed version. Disable an accepted signal through `.repocure.toml` rather than modifying RepoCure.
